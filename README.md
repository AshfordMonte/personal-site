# Gage Ashford

My personal site built with Astro framework.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Spotify

The music page reads top artists and tracks from Spotify using:

```sh
SPOTIFY_CLIENT_ID
SPOTIFY_CLIENT_SECRET
SPOTIFY_REFRESH_TOKEN
```

`.env` locally and Cloudflare Pages environment variables in production.
